# Jemm App

Consumer companion app prototype (static HTML, CSS, and JavaScript).

**Repo:** https://github.com/erikjemmai/jemm-app  
**Live:** https://erikjemmai.github.io/jemm-app/

## Run locally

```bash
python3 serve.py
```

Then open http://localhost:5175

This build is a prototype with sample data, not a production app.

Sign in with any email and password, or use **Quick setup** to pair a demo Arc. Use the presence chips on Home to walk between rooms or go away.
